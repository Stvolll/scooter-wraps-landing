# 📐 Правила позиционирования 3D-моделей

## 🎯 ОБЯЗАТЕЛЬНОЕ ПРАВИЛО

**Любая новая загруженная модель должна иметь те же координаты и масштаб, что имеют Yamaha NVX / Honda PCX / Honda Vision и другие подобные им модели.**

Это правило **ОБЯЗАТЕЛЬНО** для всех моделей в проекте.

---

## 📋 Базовые координаты (зафиксированы для всех моделей)

### Позиция модели (Model Position)
```
Position: (0, 0, 0) - центр координат
Rotation: (0, 0, 0) - без поворота
Scale: (1, 1, 1) - без масштабирования
```

### Позиция камеры (Camera Position)
```
Camera Orbit: -90deg 90deg 2.5m
  - theta: -90deg (строго боковой вид с противоположной стороны)
  - phi: 90deg (строго горизонтальный вид, не сверху, не снизу)
  - radius: 2.5m (расстояние от камеры до модели)

Camera Target: 0m 0.5m 0m
  - x: 0m
  - y: 0.5m (центр обзора на уровне центра модели)
  - z: 0m

Field of View: 30deg
```

### Ограничения камеры (Camera Constraints)
```
Min Distance: 1.2m
Max Distance: 4m
Min Polar Angle: 70deg
Max Polar Angle: 95deg
```

## 🔧 Техническая реализация

### Автоматическое центрирование

Все модели автоматически центрируются при загрузке через:

1. **Вычисление bounding box** - определяется центр и размер модели
2. **Компенсация смещения** - если модель имеет смещение, оно компенсируется
3. **Принудительный сброс** - позиция, вращение и масштаб сбрасываются в базовые значения
4. **Обновление матриц** - применяются изменения через `updateMatrixWorld(true)`

### Код реализации

```typescript
// components/ScooterViewer3D.tsx

// Базовые константы (зафиксированы)
const BASE_CAMERA_ORBIT = {
  theta: -90,   // -90deg
  phi: 90,      // 90deg
  radius: 2.5,  // 2.5m
}
const BASE_CAMERA_TARGET = { x: 0, y: 0.5, z: 0 }
const BASE_FIELD_OF_VIEW = 30 // 30deg

// Автоматическое центрирование модели
useEffect(() => {
  if (!scene) return

  // Вычисляем bounding box
  const box = new THREE.Box3().setFromObject(scene)
  const center = box.getCenter(new THREE.Vector3())

  // Компенсируем смещение
  if (Math.abs(center.x) > 0.001 || Math.abs(center.y) > 0.001 || Math.abs(center.z) > 0.001) {
    scene.traverse((child) => {
      if (child instanceof THREE.Mesh || child instanceof THREE.Group) {
        child.position.sub(center)
      }
    })
  }

  // Финальный сброс в базовые значения
  scene.position.set(0, 0, 0)
  scene.rotation.set(0, 0, 0)
  scene.scale.set(1, 1, 1)
  scene.updateMatrixWorld(true)
}, [scene, modelPath])
```

## 📝 Процесс добавления новой модели

### Шаги:

1. **Загрузка GLB файла**
   - Модель может иметь любое смещение в файле
   - Система автоматически центрирует её

2. **Проверка позиционирования**
   - Откройте консоль браузера
   - Проверьте логи: `📍 Model position reset to center`
   - Убедитесь, что `finalPosition: { x: '0.000', y: '0.000', z: '0.000' }`

3. **Проверка камеры**
   - Проверьте логи: `📷 Camera position set (Yamaha NVX base)`
   - Убедитесь, что камера использует базовые координаты

4. **Визуальная проверка**
   - Модель должна стоять в центре сцены
   - Камера должна быть в том же положении, что и для других моделей
   - Модель должна быть того же размера, что и другие модели

---

## ⚠️ Важные замечания

### ❌ НЕЛЬЗЯ:
- Использовать разные координаты для разных моделей
- Изменять базовые координаты без обновления всех моделей
- Игнорировать автоматическое центрирование

### ✅ МОЖНО:
- Модель может иметь любое смещение в GLB файле
- Система автоматически исправит позиционирование
- Все модели будут использовать одинаковые координаты

## 🔍 Диагностика

### Проверка в консоли браузера:

При загрузке модели должны быть логи:

```
📍 [ScooterViewer3D] Model position reset to center (base coordinates for all models):
  {
    modelPath: "/models/sh160/model.glb",
    boundingBox: {
      center: { x: "0.000", y: "0.000", z: "0.000" },
      size: { x: "...", y: "...", z: "..." }
    },
    finalPosition: { x: "0.000", y: "0.000", z: "0.000" },
    finalRotation: { x: "0.000", y: "0.000", z: "0.000" },
    finalScale: { x: "1.000", y: "1.000", z: "1.000" }
  }

📷 [ScooterViewer3D] Camera position set (Yamaha NVX base - fixed for all models):
  {
    orbit: "-90deg 90deg 2.5m",
    position: { x: "...", y: "...", z: "..." },
    target: { x: 0, y: 0.5, z: 0 },
    fov: 30
  }
```

### Если координаты не совпадают:

1. Проверьте, что модель загружается через `ScooterViewer3D`
2. Проверьте консоль на наличие ошибок
3. Убедитесь, что `useEffect` для центрирования срабатывает
4. Проверьте, что `modelPath` правильный
