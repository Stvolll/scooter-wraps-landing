# Быстрые улучшения разделов (кроме 1-2 экранов)

## 🎯 Критические улучшения (высокий приоритет)

### 1. GallerySection - Реальные изображения

**Проблема**: Используются placeholder градиенты вместо реальных фото

**Решение**:
- Подключить к базе данных (galleryImages из Design model)
- Использовать `next/image` для оптимизации
- Добавить lightbox для детального просмотра
- Реализовать lazy loading

**Код**:
```tsx
// Заменить статичные galleryItems на динамическую загрузку из БД
const designs = await prisma.design.findMany({
  where: { published: true },
  select: { galleryImages: true, title: true, scooterModel: true }
})
```

---

### 2. TestimonialsSection - Динамическая загрузка

**Проблема**: Статичные отзывы, нет связи с реальными заказами

**Решение**:
- Подключить к Deal model (где есть feedback)
- Показывать реальные отзывы клиентов
- Связывать с конкретными дизайнами

**Код**:
```tsx
// Загружать из базы
const testimonials = await prisma.deal.findMany({
  where: { 
    status: 'DELIVERED',
    feedback: { not: null }
  },
  include: { design: true }
})
```

---

### 3. ContactSection - Улучшенная форма

**Проблема**: Форма не отправляет данные, нет валидации

**Решение**:
- Создать API endpoint `/api/contact`
- Добавить реальную валидацию
- Success/error состояния
- Интеграция с email/CRM

---

### 4. ProcessSection - Дифференциация

**Проблема**: Дублирует ProductExperience "Production Process"

**Решение**:
- Переименовать в "Client Journey" или "Your Experience"
- Фокус на клиентском опыте (от заказа до получения)
- Показать взаимодействие с клиентом на каждом этапе

**Новые шаги**:
1. **CONSULTATION** - Бесплатная консультация и 3D превью
2. **ORDER** - Оформление заказа и оплата
3. **PRODUCTION** - Изготовление (связь с ProductExperience)
4. **INSTALLATION** - Установка на месте
5. **SUPPORT** - Послепродажная поддержка
