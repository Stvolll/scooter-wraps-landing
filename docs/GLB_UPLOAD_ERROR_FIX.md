# Исправление ошибки "Bad Request" при загрузке GLB файлов

## Проблема

При загрузке GLB файла `MODEL-Honda-SH160i-v1.glb` через админку возникает ошибка:
```
❌ Ошибка загрузки:
Ошибка загрузки файла: Upload failed: Bad Request
```

## Причины

1. **Недостаточная информация об ошибке** - сервер возвращал общую ошибку без деталей
2. **Проблема с валидацией** - файл мог быть помечен как невалидный из-за неправильной проверки типа
3. **Проблема с обработкой ошибок** - клиент не получал детальную информацию об ошибке

## Исправления

### 1. Улучшена обработка ошибок в API (`app/api/admin/designs/upload/route.ts`)

**До:**
```typescript
if (!isValidFile) {
  console.error('❌ Invalid file type:', {...})
  continue // Skip invalid files - это приводило к пустому массиву
}
```

**После:**
```typescript
if (!isValidFile) {
  console.error('❌ Invalid file type:', {...})
  
  // ✅ FIX: Возвращаем детальную ошибку вместо continue
  return NextResponse.json(
    {
      error: `Invalid file type for ${filename}`,
      type: 'InvalidFileType',
      filename,
      contentType,
      detectedType,
      details: {
        isImage,
        isModel,
        isVideo,
        isGLBFile,
        allowedImageTypes: ALLOWED_IMAGE_TYPES,
        allowedModelTypes: ALLOWED_MODEL_TYPES,
        allowedVideoTypes: ALLOWED_VIDEO_TYPES,
      }
    },
    { status: 400 }
  )
}
```

### 2. Улучшена обработка ошибок в клиенте (`components/FileUpload.tsx`)

**Добавлено:**
- Парсинг детальной информации об ошибке из JSON ответа
- Отображение filename, contentType, detectedType
- Отображение разрешенных типов файлов
- Улучшенное логирование для диагностики

### 3. Улучшено логирование

**Добавлено:**
- Логирование всех проверок валидации
- Детальная информация о файле при ошибке
- Информация о разрешенных типах

## Диагностика

При возникновении ошибки теперь будет показано:

1. **Точная причина ошибки** - Invalid file type, ParseError, и т.д.
2. **Информация о файле:**
   - filename
   - contentType
   - detectedType
3. **Детали валидации:**
   - isImage, isModel, isVideo
   - isGLBFile
   - Разрешенные типы файлов

## Проверка

Для проверки загрузки GLB файла:

1. Откройте консоль браузера (F12)
2. Попробуйте загрузить GLB файл
3. Проверьте логи:
   - В консоли браузера - детали ошибки
   - В терминале сервера - логи валидации

## Возможные причины ошибки

1. **Неправильный Content-Type** - файл может иметь `application/octet-stream` вместо `model/gltf-binary`
2. **Проблема с парсингом multipart/form-data** - большие файлы могут вызывать проблемы
3. **Проблема с валидацией** - файл может не проходить проверку типа

## Следующие шаги

Если ошибка сохраняется:

1. Проверьте логи сервера для детальной информации
2. Проверьте размер файла (может быть слишком большой)
3. Проверьте формат файла (должен быть валидный GLB)
4. Проверьте Content-Type в запросе
