# Удаление лишних компрессоров GLB

## Изменения

### 1. Убрана клиентская компрессия (`components/FileUpload.tsx`)

**До:**
- Использовался `compressGLBInBrowser` для сжатия GLB файлов >10MB в браузере
- Это вызывало проблемы с производительностью и ошибки загрузки

**После:**
- Убрана клиентская компрессия
- Файлы загружаются как есть
- Компрессия должна выполняться заранее через внешние инструменты (gltfpack, gltf-pipeline)

### 2. Убрана серверная компрессия (`app/api/admin/designs/upload/route.ts`)

**До:**
- Использовался `compressGLBWithDraco` для автоматического сжатия GLB файлов на сервере
- Это замедляло загрузку и могло вызывать ошибки

**После:**
- Убрана серверная компрессия
- Файлы сохраняются как есть
- Компрессия должна выполняться заранее

### 3. Исправлена ошибка ReactCurrentOwner (`components/ScooterViewer3DClient.tsx`)

**Проблема:**
- Ошибка `Cannot read properties of undefined (reading 'ReactCurrentOwner')`
- Возникала при динамическом импорте до полной инициализации React

**Решение:**
- Использован двойной `requestAnimationFrame` для гарантии полной инициализации React
- Улучшена обработка ошибок при загрузке модуля
- Добавлена проверка наличия default export

### 4. Исправлена ошибка с export (`components/ScooterViewer3D.tsx`)

**Проблема:**
- Named export `export { textureCache }` мог вызывать проблемы с динамическим импортом
- Ошибка `Uncaught SyntaxError: Unexpected token 'export'`

**Решение:**
- Убран named export
- `textureCache` доступен через замыкание, не нужен внешний экспорт

## Рекомендации

### Компрессия GLB файлов

Компрессия должна выполняться **заранее** через внешние инструменты:

1. **gltfpack** (рекомендуется):
```bash
gltfpack -i model.glb -o model-compressed.glb -c
```

2. **gltf-pipeline** (альтернатива):
```bash
gltf-pipeline -i model.glb -o model-compressed.glb -d -b -q 7
```

3. **Загрузка сжатых файлов:**
- Загружайте уже сжатые GLB файлы через админку
- Или используйте скрипты для автоматической компрессии перед загрузкой
