# Архитектурные принципы и центральная концепция сайта TXD

## 🎯 Центральная концепция

**Одна логика взаимодействия с пользователем, показывающая премиум сегмент и экспертизу в дизайне.**

### Ключевые принципы:

1. **Премиум сегмент**
   - Высококачественные материалы и визуализация
   - Профессиональный подход к каждому элементу
   - Исключительное внимание к деталям
   - Премиум позиционирование бренда

2. **Экспертиза в дизайне**
   - Демонстрация глубоких знаний в области дизайна
   - Показ процесса создания (от концепции до реализации)
   - Техническая экспертиза в материалах и технологиях
   - Профессиональный подход к визуализации

3. **Единая логика взаимодействия**
   - Последовательный UX на всех страницах
   - Единый визуальный язык (iOS 26 style)
   - Консистентная навигация и структура
   - Плавные переходы между разделами

## 🎨 Дизайн-система: iOS 26 Style

### Визуальные характеристики:

- **Glassmorphism**: Полупрозрачные элементы с размытием (`backdrop-filter: blur(20px) saturate(180%)`)
- **Цветовая палитра**:
  - Основной фон: `rgba(0, 0, 0, 1)` - `rgba(15, 15, 15, 1)`
  - Акцентные цвета: `#00FFA9` (зеленый), `#00D4FF` (голубой)
  - Текст: `white` / `white/60` / `white/40` для иерархии
  - Границы: `rgba(255, 255, 255, 0.1)` - `rgba(255, 255, 255, 0.12)`

- **Типографика**:
  - Заголовки: крупные, жирные, белые
  - Подзаголовки: средний размер, `white/60`
  - Основной текст: `white/70` - `white/80`
  - Моноширинные шрифты для технических данных

- **Эффекты**:
  - Мягкие тени с inset эффектами
  - Центральное свечение для акцентов
  - Плавные анимации (framer-motion, механические, без bounce)
  - Градиенты для кнопок и акцентов

### Компоненты:

1. **Карточки**: Закругленные углы (`rounded-3xl`), glassmorphism, тонкие границы
2. **Кнопки**: Градиенты, hover эффекты, четкие границы
3. **Формы**: Минималистичные, только нижние границы, uppercase labels
4. **Секции**: Вертикальные отступы (`py-24 md:py-32`), контейнеры с padding

## 🏗️ Архитектура компонентов

### Структура страниц:

```
app/
├── page.tsx (главная страница)
│   ├── Hero Section (3D viewer + модель селектор)
│   ├── Product Strip (карточки дизайнов)
│   └── Landing Sections
│       ├── ProductExperience (How to Apply + Production Process)
│       ├── USPSection
│       ├── ProcessSection
│       ├── GallerySection
│       ├── TestimonialsSection
│       ├── FAQSection
│       ├── CTASection
│       └── ContactSection
│
├── admin/ (админ-панель)
│   ├── designs/ (управление дизайнами)
│   └── login/ (авторизация)
│
└── designs/[model]/[slug]/ (страницы дизайнов)
```

### Ключевые компоненты:

1. **ScooterViewer** (`components/ScooterViewer.jsx`)
   - 3D визуализация с `model-viewer`
   - Применение текстур и вариантов материалов
   - Управление камерой и освещением

2. **ProductExperience** (`components/ProductExperience.tsx`)
   - Интерактивный гайд "How to Apply"
   - Процесс производства (вертикальный timeline)
   - Bento grid с визуальными элементами

3. **InteractiveScooterBlueprint** (`components/InteractiveScooterBlueprint.tsx`)
   - Интерактивная схема сцоутера
   - Hotspots для частей
   - Hover эффекты и подсказки

4. **DesignCard** (`components/DesignCard.tsx`)
   - Карточки дизайнов в Product Strip
   - Премиум визуализация
   - Ссылки на детальные страницы

## 📐 Принципы UX

### Взаимодействие с пользователем:

1. **Первое впечатление (Hero)**:
   - 3D модель сразу видна
   - Интерактивность (вращение, зум)
   - Выбор модели через кнопки
   - Плавный переход к контенту

2. **Исследование (Product Strip)**:
   - Горизонтальный скролл карточек
   - Визуальная иерархия
   - Быстрый доступ к деталям

3. **Обучение (ProductExperience)**:
   - Интерактивный гайд по применению
   - Прозрачность процесса производства
   - Технические детали без перегрузки

4. **Доверие (USP, Testimonials, FAQ)**:
   - Демонстрация преимуществ
   - Социальное доказательство
   - Ответы на вопросы

5. **Действие (CTA, Contact)**:
   - Четкие призывы к действию
   - Простая форма контакта
   - Множественные каналы связи

## 🔧 Технические принципы

### Производительность:

- Ленивая загрузка тяжелых компонентов (`next/dynamic` с `ssr: false`)
- Оптимизация 3D моделей (Draco compression)
- Оптимизация изображений (WebP/AVIF, responsive)
- Кэширование статических ресурсов

### Доступность:

- Семантический HTML
- ARIA атрибуты где необходимо
- Клавиатурная навигация
- Контрастность текста

### Масштабируемость:

- Модульная архитектура компонентов
- Переиспользуемые UI элементы
- Централизованная конфигурация (scooters.js)
- Типизация TypeScript где возможно

## 🚫 Что НЕ делать

1. **Не нарушать единый стиль**:
   - Не добавлять элементы, не соответствующие iOS 26 style
   - Не использовать случайные цвета или эффекты
   - Не создавать несогласованные компоненты

2. **Не усложнять UX**:
   - Не добавлять лишние шаги в процесс
   - Не перегружать информацией
   - Не создавать запутанную навигацию

3. **Не терять премиум позиционирование**:
   - Не использовать дешевые визуальные эффекты
   - Не упрощать до базового уровня
   - Не жертвовать качеством ради скорости разработки

4. **Не нарушать архитектуру**:
   - Не создавать дублирующий функционал
   - Не смешивать логику и представление
   - Не игнорировать существующие паттерны

## ✅ Чеклист для изменений

Перед внесением изменений в архитектуру или дизайн, убедитесь:

- [ ] Изменение соответствует центральной концепции (премиум + экспертиза)
- [ ] Стиль соответствует iOS 26 design system
- [ ] UX логика согласована с остальным сайтом
- [ ] Компонент переиспользуем и масштабируем
- [ ] Производительность не ухудшена
- [ ] Доступность сохранена
- [ ] Код следует существующим паттернам

## 📝 Приоритеты при разработке

1. **Премиум визуализация** - каждый элемент должен выглядеть дорого и профессионально
2. **Единообразие** - все должно работать по одной логике
3. **Экспертиза** - демонстрация знаний и профессионализма
4. **Производительность** - быстрая загрузка и плавные анимации
5. **Масштабируемость** - легко добавлять новый контент
