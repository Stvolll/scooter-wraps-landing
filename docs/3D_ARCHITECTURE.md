# Архитектура 3D-моделей: Три уровня

## 🏗️ Обзор

В проекте TXD существует три независимых уровня работы с 3D-контентом. Эти уровни **не взаимозаменяемы** и имеют четкое разделение ответственности.

---

## 📐 Уровень 1: 3D-модель (Mesh)

### Характеристики:
- **Геометрия**: Вершины, грани, полигоны
- **UV-развёртка**: Встроена в модель
- **Базовая текстура**: Может иметь запечённую (baked) базовую текстуру
- **Формат**: GLB/GLTF файл

### Особенности:
- ✅ Загружается **один раз** для модели скутера
- ✅ Используется **всеми дизайнами** этой модели
- ❌ Сама по себе **не содержит дизайна**
- ❌ Не меняется от дизайна к дизайну

### Пример:
```
Honda SH160:
  - /models/honda-sh160.glb (загружается один раз)
  - Используется всеми дизайнами для SH160
```

---

## 📏 Уровень 2: UV-лекала

### Характеристики:
- **Координатная система**: Маппинг 3D-координат на 2D-текстуру
- **Стабильность**: Контракт для всех дизайнов
- **Расположение**: Встроены в 3D-модель (Mesh)

### Особенности:
- ✅ **Стабильны** и не меняются от дизайна к дизайну
- ✅ Являются **контрактом** - все дизайны обязаны строго соответствовать
- ✅ **Встроены** в 3D-модель (не требуют отдельной загрузки)
- ❌ Не являются отдельными файлами

### Важно:
UV-лекала определяют, как текстуры будут накладываться на модель. Если UV-координаты изменятся, все существующие текстуры перестанут корректно отображаться.

---

## 🎨 Уровень 3: Текстуры дизайна

### Характеристики:
- **Тип**: Растровые изображения (PNG, JPG, KTX2, Basis)
- **Расположение**: Внешние файлы, по ссылкам (S3)
- **Подключение**: Image Texture nodes в Blender

### Особенности:
- ✅ **Уникальны** для каждого дизайна
- ✅ Накладываются **поверх UV**, но не являются частью модели
- ✅ Могут быть несколько типов: diffuse, normal, roughness, metallic, AO, emissive
- ❌ Не встроены в 3D-модель

### Пример:
```
Дизайн "Neon Blade" для Honda SH160:
  - Использует: /models/honda-sh160.glb (общая модель)
  - UV-лекала: встроены в модель
  - Текстуры:
    - /textures/neon-blade/diffuse.png
    - /textures/neon-blade/normal.png
    - /textures/neon-blade/emissive.png
```

```
│  3D-модель (Mesh)                   │
│  ├─ Геометрия                       │
│  └─ UV-лекала (встроены)            │
└─────────────────────────────────────┘
           ↑
           │ использует
           │
┌─────────────────────────────────────┐
│  Текстуры дизайна                   │
│  ├─ Накладываются поверх UV         │
│  └─ Внешние файлы (S3)              │
└─────────────────────────────────────┘
```

## 📋 Процесс работы

### 1. Создание 3D-модели (Mesh)
1. Моделирование геометрии в Blender
2. Создание UV-развёртки
3. Экспорт в GLB/GLTF
4. Загрузка в S3 (один раз для модели)

### 2. Работа с UV-лекалами
1. UV-лекала создаются в процессе моделирования
2. Встраиваются в GLB файл
3. Не требуют отдельной загрузки
4. Стабильны для всех дизайнов модели

### 3. Создание текстур дизайна
1. Создание текстур в графическом редакторе
2. Следование UV-координатам модели
3. Экспорт в PNG/JPG/KTX2
4. Загрузка в S3 (уникально для каждого дизайна)
5. Подключение как Image Texture nodes

---

## ⚠️ Важные правила

### ❌ НЕЛЬЗЯ:
- Изменять UV-лекала для отдельных дизайнов
- Загружать новую 3D-модель для каждого дизайна
- Встраивать текстуры дизайна в GLB файл

### ✅ МОЖНО:
- Использовать одну 3D-модель для всех дизайнов модели скутера
- Создавать уникальные текстуры для каждого дизайна
- Загружать несколько типов текстур (diffuse, normal, etc.)

---

## 🗄️ Хранение в базе данных

### Design Model:
```prisma
model Design {
  scooterModel       String  // Модель скутера
  glbModelUrl        String? // 3D-модель (Mesh) - общая для модели
  textures           DesignTexture[] // Текстуры - уникальны для дизайна
}

model DesignTexture {
  designId   String
  url        String  // S3 URL текстуры
  type       String  // "diffuse" | "normal" | "roughness" | etc.
  layer      Int     // Слой текстуры
}
```

### Логика:
- `glbModelUrl` хранится в Design, но должен быть одинаковым для всех дизайнов одной модели
- `textures` - уникальны для каждого дизайна
- UV-лекала не хранятся отдельно - они встроены в GLB файл

---

## 🎯 Рекомендации

1. **При создании новой модели скутера:**
   - Создайте 3D-модель с правильной UV-развёрткой
   - Загрузите её один раз
   - Используйте для всех последующих дизайнов

2. **При создании нового дизайна:**
   - Выберите модель скутера
   - Система автоматически использует существующую 3D-модель
   - Загрузите только текстуры дизайна

3. **При изменении UV-лекал:**
   - Это критическое изменение
   - Требует обновления всех существующих текстур
   - Должно быть согласовано с командой дизайнеров
