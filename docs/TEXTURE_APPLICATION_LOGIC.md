# Логика применения текстур к 3D модели

## 🎯 Основной принцип

**Базовая 3D-модель (Mesh) всегда остается неизменной. Текстуры дизайна накладываются поверх базовой модели.**

## 📐 Архитектура

### Уровень 1: Базовая модель (Mesh)
- **Файл**: `MODEL_Honda SH160i_.glb`
- **Содержит**: Геометрию и UV-развёртку
- **Статус**: Неизменна, используется для всех дизайнов

### Уровень 2: UV-лекала
- **Расположение**: Встроены в базовую модель
- **Статус**: Стабильны, не меняются

### Уровень 3: Текстуры дизайна
- **Формат**: `.webp` файлы
- **Применение**: Накладываются поверх базовой модели
- **Координаты**: Соответствуют UV-лекалам базовой модели

## 🔄 Процесс применения текстур

1. **Загрузка базовой модели**
   ```typescript
   const gltf = useGLTF(modelPath) // Всегда базовая модель
   ```

2. **Определение текстур дизайна**
   ```typescript
   if (selectedDesign.textures) {
     // Применяем текстуры к базовой модели
     textureSet = selectedDesign.textures
   }
   ```

3. **Применение текстур к материалам**
   ```typescript
   scene.traverse(node => {
     if (node instanceof THREE.Mesh && node.material) {
       // Находим материал по имени
       // Применяем соответствующую текстуру
       material.map = texture
     }
   })
   ```

## ⚠️ Важно

### Базовая модель НЕ заменяется

- ❌ **НЕ используем** `designGlb` для замены базовой модели
- ✅ **ВСЕГДА используем** базовую модель из `modelPath`
- ✅ **Текстуры накладываются** поверх базовой модели

### GLB файлы с дизайном

GLB файлы с дизайном (`designGlb`) могут существовать, но они:
- Используются только как **reference** (для справки)
- Находятся в тех же координатах, что и базовая модель
- **НЕ заменяют** базовую модель
- **НЕ загружаются** в 3D-вьювер

## 📝 Пример конфигурации

```javascript
{
  id: 'sh160',
  name: 'Honda SH160i',
  model: '/models/sh160/model.glb', // Базовая модель (всегда используется)
  designs: [
    {
      id: '01',
      name: 'Design 1',
      // Текстуры накладываются на базовую модель
      textures: {
        body: '/textures/sh160/design-1/a-face.webp',
        plastic: '/textures/sh160/design-1/rl-place.webp',
        accents: '/textures/sh160/design-1/z-parts.webp',
      },
      // Reference GLB (не используется для замены)
      designGlb: '/models/sh160/design-1.glb',
    }
  ]
}
```

## 🔍 Проверка работы

1. Откройте консоль браузера
2. Выберите дизайн
3. Проверьте логи:
   - `🎨 Loading texture:` - текстуры загружаются
   - `✅ Texture applied:` - текстуры применены к базовой модели
   - Базовая модель остается той же (не перезагружается)

## 🎨 Преимущества подхода

1. **Производительность**: Базовая модель загружается один раз
2. **Гибкость**: Легко менять дизайны без перезагрузки модели
3. **Кеширование**: Текстуры кешируются для быстрой перезагрузки
4. **Согласованность**: Все дизайны используют одну и ту же геометрию
