## 📋 ОБЗОР

Система пакетной загрузки позволяет загружать все файлы для одного дизайна одновременно, с подсказками на русском языке и валидацией параметров.


## 📦 ТИПЫ ФАЙЛОВ

### 1. **Обложка (Cover Image)**
- **Назначение:** Главное изображение для карточек
- **Формат:** JPG, PNG, WebP
- **Разрешение:** 1200x800px (рекомендуется)
- **Размер:** до 500KB
- **Пример:** `neon-blade-cover.webp`

### 2. **Галерея (Gallery Images)**
- **Назначение:** Дополнительные фото дизайна
- **Формат:** JPG, PNG, WebP
- **Разрешение:** 1920x1080px
- **Размер:** до 5MB
- **Количество:** 3-5 изображений (рекомендуется)
- **Пример:** `neon-blade-gallery-01.webp`

### 3. **3D Модель (GLB)**
- **Назначение:** Основная 3D модель скутера
- **Формат:** GLB (binary GLTF)
- **Размер:** до 50MB
- **Рекомендация:** Использовать Draco-сжатие
- **Пример:** `honda-vision-neon-blade.glb`

### 4. **3D Модель (GLB, сжатая)**
- **Назначение:** Сжатая версия для быстрой загрузки
- **Формат:** GLB с Draco
- **Размер:** до 20MB
- **Пример:** `honda-vision-neon-blade-compressed.glb`

### 5. **3D Модель (GLB, мобильная)**
- **Назначение:** Упрощенная версия для мобильных
- **Формат:** GLB
- **Размер:** до 10MB
- **Пример:** `honda-vision-neon-blade-mobile.glb`

### 6. **Текстура (Texture)**
- **Назначение:** Текстура для 3D модели
- **Формат:** PNG, JPG, KTX2
- **Разрешение:** 2048x2048px (степени двойки)
- **Размер:** до 10MB
- **Типы:** diffuse, normal, roughness, metallic, ao
- **Пример:** `honda-vision-neon-blade-texture.png`

### 7. **Видео (Preview)**
- **Назначение:** Превью видео дизайна
- **Формат:** MP4, WebM
- **Размер:** до 100MB
- **Длительность:** 15-30 секунд (рекомендуется)

### 8. **Видео (Полное)**
- **Назначение:** Полное видео дизайна
- **Формат:** MP4, WebM
- **Размер:** до 500MB

### 9. **Видео (Инструкция)**
- **Назначение:** Видео-инструкция по применению
- **Формат:** MP4, WebM
- **Размер:** до 200MB

### 10. **Схема (SVG)**
- **Назначение:** Векторная схема для раздела "How to Apply"
- **Формат:** SVG
- **Размер:** до 10MB
- **Пример:** `honda-vision-blueprint.svg`

### 11. **Инструкция (PDF)**
- **Назначение:** PDF инструкция по применению
- **Формат:** PDF
- **Размер:** до 10MB
- **Пример:** `honda-vision-instruction.pdf`

### 12. **Миниатюра (Thumbnail)**
- **Назначение:** Миниатюра для быстрого отображения
- **Формат:** JPG, PNG, WebP
- **Разрешение:** 400x400px
- **Размер:** до 500KB

### 13. **Превью для соцсетей**
- **Назначение:** Изображение для Open Graph
- **Формат:** JPG, PNG
- **Разрешение:** 1200x630px
- **Размер:** до 2MB

## ⚙️ СВОЙСТВА 3D МОДЕЛИ

### Позиция камеры
- **X, Y, Z:** Координаты камеры
- **Получение позиции:** Используйте `window.getCurrentCameraPosition()` в консоли браузера

### Освещение
- **Ambient:** Окружающее освещение (0-1)
- **Shadows:** Включение теней

### Материалы
- **Metalness:** Металличность (0-1)
- **Roughness:** Шероховатость (0-1)

## 📝 ПРОЦЕСС ЗАГРУЗКИ

1. **Выберите тип файла** из выпадающего списка
2. **Прочитайте подсказки** о параметрах файла
3. **Перетащите файлы** в зону загрузки или нажмите для выбора
4. **Проверьте список** загруженных файлов
5. **Нажмите "Загрузить все файлы"** для начала загрузки
6. **Дождитесь завершения** - прогресс отображается для каждого файла

## 🔧 ТЕХНИЧЕСКИЕ ДЕТАЛИ

### API Endpoints

- `POST /api/designs/[id]/assets/batch` - Пакетная загрузка файлов
- `POST /api/designs/[id]/model-properties` - Сохранение свойств модели
- `GET /api/designs/[id]/model-properties` - Получение свойств модели

### Структура БД

```prisma
model Design {
  // ... основные поля ...
  textures         DesignTexture[]
  modelProperties  DesignModelProperties?
  // ... дополнительные поля для файлов ...
}

model DesignTexture {
  url        String
  type       String  // "diffuse" | "normal" | "roughness" | ...
  format     String  // "png" | "jpg" | "ktx2"
  resolution String?
  layer      Int
}

model DesignModelProperties {
  cameraPosition Json?
  cameraTarget   Json?
  lighting       Json?
  materials      Json?
  environmentMap String?
}
```

## 💡 СОВЕТЫ ПО ОПТИМИЗАЦИИ

1. **Используйте WebP** для изображений (меньший размер при том же качестве)
2. **Сжимайте GLB** с помощью `gltf-pipeline` или `gltfpack`
3. **Используйте KTX2** для текстур (лучшая производительность)
4. **Оптимизируйте видео** перед загрузкой
5. **Используйте правильные разрешения** (степени двойки для текстур)

## ❓ ЧАСТО ЗАДАВАЕМЫЕ ВОПРОСЫ

**Q: Можно ли загрузить несколько файлов одного типа?**  
A: Да, для типа "Галерея" поддерживается множественная загрузка.

**Q: Как получить позицию камеры?**  
A: Откройте консоль браузера на странице с 3D моделью и выполните `window.getCurrentCameraPosition()`.

**Q: Какие форматы текстур поддерживаются?**  
A: PNG, JPG, KTX2, Basis Universal. Рекомендуется KTX2 для лучшей производительности.

**Q: Где хранятся загруженные файлы?**  
A: Все файлы загружаются в S3 хранилище в папку `designs/[design-slug]/[category]/`.
